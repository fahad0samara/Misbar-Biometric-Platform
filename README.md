# مِسبار للصحة والأداء الرياضي | Misbar Biometric & Athletic Performance Platform

منصة تحليل حيوي وطبي متقدمة لمتابعة الاستشفاء العضلي، تقلب معدل ضربات القلب (HRV rMSSD / SDNN)، هندسة النوم الفسيولوجية، ونسبة الحمل التدريبي الحاد إلى المزمن (ACWR) للرياضيين النخبة، مع توافق كامل مع معايير التبادل الطبي المهيكل (**HL7 FHIR R4**) والمركز السعودي لاعتماد المنشآت الصحية (**سباهي CBAHI**) والهيئة العامة للغذاء والدواء (**SFDA**).

---

## المزايا الرئيسية | Key Features

### 1. لوحة الصحة الشاملة (Comprehensive Biometric Overview)
- **حلقات الجاهزية الحيوية الثلاث**: عرض فوري لمؤشر الاستشفاء اليومي، كفاءة وجودة النوم، ومؤشر الإجهاد البدني مع توصية تدريبية مباشرة لكل حلقة.
- **منحنى تقلب معدل ضربات القلب (HRV rMSSD) ونبض الراحة (RHR)**: مخطط ثنائي المحور (7 أو 14 يوماً) مع نطاق الأساس الفردي (SWC) وتوجيه تدريبي تفاعلي عند النقر على أي يوم.
- **مخطط مراحل النوم التراكمي وتوزيع الدورات**: تحليل دقيق للنوم العميق البنائي (SWS)، نوم حركة العين السريعة (REM)، والنوم الخفيف مقارنةً بهدف الـ 8 ساعات، مع شريط تقدم معياري لمراحل النوم.
- **مخططات التوجيه الصحي والتدريبي (Advisory Charts)**:
  - مخطط مقارنة المؤشرات الحيوية الستة بالمعيار المرجعي للرياضي (Bullet Target Bars).
  - مصفوفة القرار التدريبي اليومي (مخطط تشتت ثنائي الأبعاد للاستشفاء مقابل الإجهاد البدني) لتحديد منطقة التدريب المثلى.
- **مخطط رادار الجاهزية (Spider Radar)**: تقييم متعدد الأبعاد لـ 6 محاور فسيولوجية مقارنةً بخط الأساس.
- **مخطط نسبة الحمل التدريبي الحاد إلى المزمن (ACWR)**: تتبع الحمل الحاد (7 أيام) والمزمن (28 يوماً) مع تحديد المنطقة الآمنة (`0.80 – 1.30`) وعتبة خطر الإصابة (`1.30+`).

### 2. خريطة العضلات التفاعلية والوقاية من الإصابات (Interactive Anatomical Recovery Map)
- **مجسم تشريحي أمامي وخلفي متزامن**: تلوين حيوي لـ 6 مجموعات عضلية رئيسية حسب نسبة الاستشفاء وتراكم الإجهاد الميكانيكي.
- **نافذة بروتوكول التعافي العضلي المخصص (Interactive Recovery Modal)**: عند النقر على أي عضلة في المجسم أو أشرطة العضلات، تفتح نافذة منبثقة تعرض:
  - بروتوكول الإطالة الحركية والعصبية (Stretching Protocol) مع المدة والتكرارات.
  - بروتوكول التدليك واللفافة العضلية (Myofascial Release) ومستوى الضغط الموصى به.
  - بروتوكول التبريد والعلاج الحراري المائي (Cryotherapy / Contrast Therapy) ودرجة الحرارة المثلى.
- **ربط الاستشفاء العضلي بالسوائل والأملاح (Hydration & Electrolyte Engine)**: حساب تلقائي لاحتياج السوائل اليومي (لتر)، الصوديوم (`Na+`)، البوتاسيوم (`K+`)، والمغنيسيوم (`Mg2+`) بناءً على حالة العضلات المجهدة وحمل الحصة التدريبية، مع جدول زمني للتعويض (قبل، أثناء، وبعد التمرين).

### 3. رادار HRV وهندسة النوم الفسيولوجية (HRV Radar & Sleep Architecture)
- **مخطط بوانكاريه للتوازن العصبي اللاإرادي (Poincaré Plot RR_n vs RR_{n+1})**: تمثيل هندسي لانتشار فترات النبض (`SD1` قصير المدى و`SD2` طويل المدى) لقياس سيادة العصب الحائر.
- **تخطيط مراحل النوم الليلي (Nightly Sleep Hypnogram)**: تتبع دورات النوم الخمس عبر ساعات الليل مع تحديد نافذة إفراز هرمون النمو البنائي.
- **محاكاة السيناريوهات الفورية**: إمكانية التبديل بنقرة واحدة بين «ليلة إجهاد الماراثون» و«قراءة ذروة الاستشفاء» أو تعديل المؤشرات عبر أشرطة المعايرة الحية.

### 4. إدارة الأجهزة القابلة للارتداء والحساسات الطبية (Wearable Sensors & Telemetry)
- دعم مزامنة البيانات الحية مع الأجهزة المعتمدة من **SFDA**:
  - **سوار Whoop 4.0 Pro** (PPG متعدد الأطوال الموجية + حساس حرارة الجلد).
  - **خاتم Oura Ring Gen 4** (حساسات الأشعة تحت الحمراء ومقياس حرارة NTC).
  - **حزام الصدر Polar H10 ECG** (تخطيط قلب كهربائي بدقة `1000Hz`).
  - **ساعة Garmin Forerunner 965** (تتبع أحمال الجري وتشبع الأكسجين `Pulse Ox`).
- دعم استيراد ملفات القياسات الحيوية بصيغتي `JSON` و`CSV`.

### 5. التقرير الطبي المعتمد والتصدير المهيكل (Clinical Export Studio)
- توليد وتصدير حزم **HL7 FHIR R4 Bundle** متوافقة مع ترميز **LOINC** (`80404-7` لـ HRV rMSSD، `8867-4` لنبض الراحة، `93832-4` للنوم) ومعايير **سباهي (CBAHI)**.
- تصدير جداول البيانات السريرية بصيغة **CSV** وإمكانية الطباعة الرسمية مع ملاحظات الطبيب الاستشاري المشرف.

## الهوية البصرية والتصميم | Design & Architecture

- **نظام ألوان تراثي طبي عالي التباين**: خلفية ورق البردي الدافئ (`#F4F0E6`) مع الأخضر الزمردي الداكن (`#0B5D46`) والذهبي النحاسي (`#B8955A`) لضمان قراءة مريحة للعين تحت مختلف ظروف الإضاءة.
- **الخطوط العربية والرقمية**:
  - خط العناوين: `Readex Pro`
  - خط النصوص والتقارير الطبية: `IBM Plex Sans Arabic`
  - خط الأرقام والقياسات الحيوية (`tabular-nums`): `IBM Plex Mono`
- **استجابة كاملة لجميع الشاشات (Responsive RTL Layout)**:
  - تخطيط مرن (`CSS Grid` & `Flexbox`) يدعم الجوال، الأجهزة اللوحية، والشاشات العريضة دون أي تمرير أفقي زائد (`overflow-x: hidden`).
  - رسوم بيانية متجهة (`SVG`) ذات أبعاد قياسية متجاوبة تحافظ على وضوح التسميات والقيم في مختلف أحجام الشاشات.

## هيكل المشروع | Project Structure

```text
├── index.html                        # نقطة الدخول وتحميل خطوط Google Fonts واتجاه RTL
├── metadata.json                     # بيانات تعريف التطبيق
├── package.json                      # الاعتماديات وسكربتات التشغيل والبناء
├── src/
│   ├── App.tsx                       # الواجهة الرئيسية، إدارة الحالة، والتنقل بين التبويبات الخمسة
│   ├── index.css                     # إعدادات Tailwind CSS v4، أنماط الطباعة، وضبط الاستجابة
│   ├── main.tsx                      # نقطة ربط تطبيق React
│   ├── components/
│   │   ├── BiometricCharts.tsx       # جميع المخططات التفاعلية، خريطة العضلات، ونافذة بروتوكول التعافي
│   │   └── IslamicPatterns.tsx       # الزخارف الهندسية الإسلامية (Girih & Mashrabiya SVG) وإطارات البطاقات
│   ├── data/
│   │   └── biometricEngine.ts        # محرك الحسابات الفسيولوجية، بيانات 14 يوماً، ومولد تقارير FHIR/CSV
│   └── types/
│       └── biometrics.ts             # تعريفات TypeScript للسجلات الحيوية، العضلات، والأجهزة
```

## التشغيل المحلي | Local Development

1. **تثبيت الاعتماديات (Install Dependencies)**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير (Start Dev Server on Port 3000)**:
   ```bash
   npm run dev
   ```

3. **فحص الأنواع وبناء نسخة الإنتاج (Typecheck & Build)**:
   ```bash
   npm run lint
   npm run build
   ```
